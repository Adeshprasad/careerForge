# CareerForge

CareerForge is a backend-heavy MERN application designed to help users track, manage, and organize their job applications in one place.

The project is being built from scratch with a focus on understanding the architecture and implementation rather than simply assembling features.

## Tech Stack

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Multer

### Frontend
- React
- Vite
- JavaScript

## Features

### Application Management
- Create job applications
- View applications
- Update applications
- Delete applications
- Search applications by company
- Filter applications by status
- Pagination
- Sort applications
- Resume upload

### Authentication & Security
- User registration and login
- JWT-based authentication
- Protected routes
- User-specific application data
- Request validation

### Frontend
- Reusable React components
- Props and component-based architecture
- React state management
- Controlled form inputs
- Application cards
- Dynamic list rendering
